# ERYING i9-11900H ES Hackintosh — RX 580

Baseado no projeto público de Forte500/ERYING-i9-11900H-ES-Hackintosh.

Este clone será adaptado para:
- ERYING THM570
- Intel Core i9-11900H ES
- 16 GB DDR4-3200
- AMD Radeon RX 580
- SSD SATA Kingston 480 GB

A EFI será mantida com foco em BIOS stock THM570111 quando aplicável.
